# Portfólio — Pedro Martins

Site pessoal em HTML/CSS/JS puro — sem build, sem dependências — pronto para publicar no GitHub Pages.

## Ver localmente
Basta abrir `index.html` no navegador.

## Publicar no GitHub Pages
1. Crie um repositório no GitHub (pode ser `seu-usuario.github.io` ou qualquer outro nome).
2. Suba os arquivos `index.html`, `style.css` e `script.js` para a raiz do repositório.
3. Em **Settings → Pages**, selecione a branch `main` e a pasta `/ (root)`.
4. Em alguns minutos o site fica no ar em `https://seu-usuario.github.io/nome-do-repositorio/`.

## Pendências para você preencher
- [ ] Link do GitHub em Contato — hoje está como placeholder (`github.com/SEU-USUARIO`)
- [ ] Decidir se quer incluir telefone no site público — deixei de fora de propósito (fica exposto a qualquer robô de spam), mas o e-mail e o LinkedIn já estão com seus dados reais
- [ ] Foto ou avatar — opcional, o design funciona sem, mas dá pra encaixar no hero ou na seção Sobre se quiser

## Estrutura
- `index.html` — conteúdo e estrutura
- `style.css` — todo o visual (cores, tipografia, layout, responsivo)
- `script.js` — menu mobile, animação de entrada ao rolar, ano do rodapé
